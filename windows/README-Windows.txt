Cricket Scores — Windows portable version

1. Extract the ZIP file to a folder you can write to, such as Downloads or Documents.
2. Copy newsapi.env.example to newsapi.env.
3. Open newsapi.env in Notepad and replace put-your-key-here with your NewsAPI.ai key.
4. Double-click CricketScores.exe.

This is a portable per-user build. It does not install a service, write to Program Files, change the registry, or request administrator permission. Keep newsapi.env private and do not share it.

The app needs an internet connection to refresh live scores, schedules, player profiles, and cricket news. Windows Defender SmartScreen may show a warning because this personal build is not code-signed. If you trust the source, use More info and Run anyway according to your organization's security policy.
